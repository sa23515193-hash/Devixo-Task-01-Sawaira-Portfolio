
# Personal Portfolio Website

A modern, responsive personal portfolio website developed as part of **Devixo Internship — Task 01**.

The website presents my educational background, technical skills, projects, achievements, certificates, and contact details in a structured and professional layout.

## 🚀 Project Overview

This portfolio serves as a professional online profile where visitors can explore my work, review my technical capabilities, learn about my education and achievements, and contact me for professional opportunities.

## ✨ Features

- Responsive layout for desktop, tablet, and mobile screens
- Professional hero section with introduction and call-to-action buttons
- About Me section
- Technical skills section
- Education details
- Project showcase with six image slots
- Separate achievements and certificates sections
- Achievement image slots for:
  - Vinix Student ID card
  - PTE Pakistan Campus Ambassador ID card
  - PTE Pakistan Campus Ambassador training certificate
  - Zidio Development Data Science & Analytics internship certificate
- Hire Me and Contact Me buttons
- Email, LinkedIn, and phone contact options
- Footer with essential information
- CSS transitions and visual effects

## 🛠️ Technologies Used

- **HTML5** — Semantic page structure
- **CSS3** — Styling, layouts, animations, and responsive design
- **JavaScript** — Interactive interface elements, where applicable

## ▶️ How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure the HTML, CSS, JavaScript, and image files are in their correct locations.
4. Open `index.html` in a web browser.
5. Alternatively, use the Live Server extension in VS Code.
